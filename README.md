# Indecision App

![Indecision App](public/images/favicon.svg)

A lightning-fast, ultra-modern React application designed to solve the age-old problem of decision paralysis. Built with an uncompromising focus on UI/UX, this app leverages state-of-the-art React architecture to effortlessly make your toughest choices for you.

## 🌟 Features

- **Algorithmic Decision Making**: Offload your cognitive burden to our highly optimized, randomized selection engine
- **Multi-Theme Engine**: Seamlessly switch between Light, Dark, and a retro Terminal theme instantly
- **Glassmorphism UI**: Beautiful, premium design elements with smooth gradients and soft shadows
- **Lightning Fast**: Built on Webpack 5 with optimized asset delivery and zero-latency interactions
- **Responsive Design**: Pixel-perfect layouts that adapt flawlessly to any device
- **Persistent Storage**: Never lose a task again with our hyper-reliable `localStorage` integration
- **Modern Typography**: Elegant integration of `Playfair Display` and `Inter` fonts for an elite reading experience

## 🛠️ Tech Stack

- **Frontend**:
  - React (JSX, Class & Functional Components)
  - Webpack 5 (Asset Bundling)
  - Babel (ES6+ Transpilation)
  - SCSS (Advanced Styling & Theming)

- **Key Libraries**:
  - React Icons (Premium SVG Iconography)
  - Normalize.css (Cross-browser Consistency)

## 🎯 Core Functionality

- **Task Management**:
  - Lightning-fast entry with auto-focusing inputs
  - One-click absolute list clearing
  - Individual item deletion with sleek micro-animations
  
- **Action Engine**:
  - The massive "What should I do?" button guarantees an immediate, unbiased decision
  - Intelligent disabling logic prevents erroneous executions

- **UI/UX**:
  - Dynamic state management based on user interaction
  - Pixel-perfect layout stability (zero jarring layout shifts)
  - Highly accessible focus rings and responsive cursors

## 📝 Project Structure

```
src/
├── components/     # High-performance React components
├── context/        # React Context API for global state (Theming)
├── styles/         # Scalable SCSS architecture (BEM methodology)
│   ├── base/       # Core variables and resets
│   └── components/ # Scoped component styling
├── app.jsx         # Application entry point
```

## 🎨 Design Choices

- **Minimalist UI**: Clean, distraction-free interface focused purely on action
- **Typography**: A curated blend of `Playfair Display` for elegant branding, `Inter` for unparalleled legibility, and `Space Mono` for the retro Terminal experience
- **Color Scheme**: Meticulously crafted palettes (pure blacks, crisp whites, and gentle off-grays) that prevent eye strain and ooze premium quality
- **Micro-interactions**: Subtle hover states, focus rings, and scale animations that make the application feel truly alive
